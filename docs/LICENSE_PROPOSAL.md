# Code license proposal, pending owner decision

Proposal for review: MIT for code owned by the personal maintainer, if the owner chooses public reuse with attribution and the MIT warranty disclaimer. No license is selected or granted by this proposal. Public source publication remains pending the owner's explicit decision, confirmation of copyright ownership and chosen copyright wording.

If approved, add the exact MIT license as a root LICENSE with the confirmed holder and year. If a different license or private source is chosen, record that instead. Do not apply the chosen code license to assets or dependency code owned by others. Fonts retain SIL OFL 1.1, Hebcal data retains CC BY 4.0, and unverified photos/brand assets require their own permission.
